纯稚学 · 静态站部署说明
======================

本目录即 MkDocs 站点根目录（docs_dir 直接设为当前文件夹，md 不用复制副本）。
改完任何 .md，push 到 GitHub 后 Railway 会自动重新构建。


一、本地预览（可选，装了 Docker 就能跑）
---------------------------------------
  docker run --rm -it -p 8000:8000 -v "${PWD}:/docs" squidfunk/mkdocs-material serve -a 0.0.0.0:8000
然后浏览器打开 http://localhost:8000


二、部署到 Railway（Docker 路线）
---------------------------------
1. 把整个文件夹初始化成 git 仓库并推到你自己的 GitHub：
     cd "D:\Documents\agent_workspace\纯雉学说"
     git init
     git add .
     git commit -m "纯稚学说静态站"
     git branch -M main
     git remote add origin https://github.com/<你的账号>/<仓库名>.git
     git push -u origin main

2. 打开 https://railway.app  → New Project → Deploy from GitHub repo → 选这个仓库。
   Railway 会自动识别本目录的 Dockerfile 并构建。

3. 构建完成后，进入 service → Settings → Networking：
   - "Expose Port" / 目标端口填 80（本 Dockerfile 里 nginx 监听 80）。
   - 点 "Generate Domain" 生成公网域名，即可分享。

4. 以后每次改完 md：
     git add . ; git commit -m "更新" ; git push
   Railway 检测到 push 会自动重新部署。


三、想换成 Zensical（同一作者的下一代生成器）
-----------------------------------------------
把 Dockerfile 第一阶段镜像换成 zensical/zensical，并把构建命令从
  RUN mkdocs build
换成
  RUN zensical build
同时把 mkdocs.yml 改写成 zensical.toml（TOML 格式）。其余 nginx 托管、Railway
配置完全不变。31 篇小品文用默认的 MkDocs Material 即可，不必折腾。


四、注意
--------
- #25 小王子与玫瑰、#32 用户需求与场景拆解 暂无 md 文件，nav 里没列；
  以后补了 .md，在 mkdocs.yml 的 nav 里对应位置加一行即可。
- 中文文件名在网址里会被自动转码，浏览器可正常打开。
