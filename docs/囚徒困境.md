## 0 一句话概括

作者给纯稚搭了一个标准的**囚徒困境**博弈：两人都选"和好"是帕累托最优（8,8），但**单方面硬扛着不和好对自己短期最爽**（10），于是双方各自的占优策略都指向"不和好"，最后双双落到 (4,4) 的次坏均衡——**这就是青稚裹着 999 毯子哭、白小纯"土皇帝迁都"的数学本质：两个人都想赢，结果一起输。**

## 1 先建效用函数（图3）

作者先定义两人各自的"爽值/幸福感"从哪来：

> **U(青稚) = f(竞技成绩、共同进步、白小纯的温柔)**
> **U(白小纯) = g(竞技成绩、尊重且低压的团队氛围、青稚服软让步)**

关键的相互掣肘（caption 原文）：
- 青稚从竞技成绩里拿到的爽值比白小纯更高；而他**想和白小纯共同出成绩，就会去 push 白小纯**——push 在白小纯那里等于"不被尊重"。
- 所以：**青稚的正爽值，恰好是白小纯的负爽值。**
- 反过来，白小纯的"温柔包容"要在青稚**服软让步**时才给得出；而青稚的服软让步，又只在白小纯**强硬**时才被激发。
- 结论：**两个人的情感需求本质上是互相违背的。**

## 2 博弈矩阵（图1）

行 = 青稚的选择，列 = 白小纯的选择；每格 (青稚效用, 白小纯效用)：

| | 白小纯：和好 | 白小纯：不和好 |
|---|---|---|
| **青稚：和好** | **(8, 8)** 重归于好、一起冲冠 | **(2, 10)** 青稚热脸贴冷屁股 |
| **青稚：不和好** | **(10, 2)** 白小纯低头、青稚拿温柔 | **(4, 4)** 冷战保底 |

四个格子逐一拆：

1. **(和好, 和好) = (8, 8)**：两人重归于好、一起回战场冲冠。这是 8+8=16 > 10+2=12 > 4+4=8 的**帕累托最优**，也是网友最想看到的结局。——那白小纯当下为什么不选？
2. **(和好, 不和好) = (2, 10)**：**这正是现在的局面。** 青稚放低姿态示好、被白小纯强硬拒绝。青稚爽值几乎归零，还倒贴难堪、挫败、委屈，再也没有白小纯当年"大哥哥式"挡酒、递咖啡的温柔——于是出现了**裹着 999 毯子哭、"土皇帝迁都"** 的泪海名场面。而白小纯不和好：不用承担修复关系的心理成本、不用回到高压搭档环境、不用主动妥协（规避再受伤）；**最关键的是，他的强硬能一直激发青稚"主动服软让步"的人格**——短期看这是他最舒服的选择。
3. **(不和好, 和好) = (10, 2)**：青稚不松口、白小纯主动和好（目前不存在，纯推演）。一旦白小纯服软温柔，青稚那套强势高标准的竞技人格又被激活，重新认定"我 push 队友是对的"，于是又会退回不和好——问题根本没解决，白小纯还是会回到过去的状态。
4. **(不和好, 不和好) = (4, 4)**：双方都不选和好。不用再磨合、不用吵架、不用承担修复失败的风险，也没有新增心理伤害；利弊抵消，是"不完美但也不会更受伤"的**保底状态**，所以取中间值 4。

## 3 占优策略推导（图2）

作者用红字标出每一方的最优回应：

- 若青稚选和好：白小纯选和好得 8、选不和好得 10 → **不和好更划算**。
- 若青稚选不和好：白小纯选和好得 2、选不和好得 4 → **还是不和好更划算**。
- 所以**无论青稚怎么选，"不和好"都是白小纯的占优策略**；镜面照过来，对青稚也一样。

→ 两人占优策略的交点 = **(不和好, 不和好) = (4, 4)**，这才是稳定均衡。
→ 眼下"(青稚想和好, 白小纯不和好)=(2,10)"是**不稳定的**：青稚在 2 的位置上太难受，会赌气/为自尊转向不和好去拿 4，于是把对方的效用从 10 也拉到 4——**这就是"恨海情天"的数学路径**。

## 4 怎么破（图2 结语）

作者点题：

> 囚徒困境之所以产生，是因为**双方彼此不信任、不知道对方会不会出卖自己、不能沟通、独自做选择，存在信息差**。如果他们能当面互通，这个困境本不存在。
> 但现在的问题是：**他们能沟通，却沟通不清楚，信息差依然在。**
> 破解办法 = 他俩真正理解对方，**通过沟通打破信息差、站到对方角度为对方考虑**，才能一起爬回那个 (8,8) 的帕累托最优。

## 6 理论骨架（整理者提炼）

1. **这是全集里唯一一个带"支付矩阵"的硬模型。** 它不解释"他们是什么关系"，而是解释"为什么明明和好比不合好强，两人却卡在不合好"——答案是个体理性的加总不等于集体理性。
2. **核心洞见：青稚的爽=白小纯的痛。** 竞技成绩、push、服软这组变量互为正负号，所以两人的效用函数在结构上**咬合又对冲**，这才是困境的根。
3. **"强硬能激发对方服软"是当下的纳什诱惑。** 白小纯短期占优不是因为他不想和好，而是因为"我硬着，他就会来软"——这是他个体最优，但把青稚推到 2，逼青稚也掉头去选 4。
4. **解法不是"谁先低头"，是"信息差被打破"。** 作者明确：能沟通但沟通不清楚 = 困境仍在；必须真的站到对方效用函数里去，才回得去 (8,8)。这与 #20 梅拉宾法则"白小纯读不懂青稚的求和语气"、#22 乡土中国"教化权力私人化"讲的是同一个病：**颗粒度没对齐。**
5. **和 #27 共价键是一对相反模型。** #27 乐观：吵完会抵达拆不开的稳态；#28 冷峻：如果信息差不打破，两人会一路滑到 (4,4)。两篇合起来才是完整的"相爱相杀"动力学。

## 8 边界

- 数字 (8/10/4/2) 是作者**示意用的大小关系**，不是测量值；换一组保持顺序的数字结论不变。
- "效用函数互相违背"是作者对节目切片的建模，真实情感要比"四象限"复杂得多——作者本人也用便签随手推导、自标"momo"匿名，属于网友智力游戏。
- 它描述的是**两人关系当下的卡点**，不预测结局；是否真能回到 (8,8)，取决于后续节目里信息差能否被打通。
