## 0 一句话概括

有人把纯稚和《再见爱人》那对"李麦"相提并论，作者急了，搬出磁铁做切割：**李麦是"一块磁铁吸住一块铁"——铁想逃、却被单向吸回去，是消耗；纯稚是"两块同性相斥的磁铁"——明明该互相弹开，却始终在同一个磁场里，斥力本身就证明他俩还在彼此作用。** 不能因为都"黏糊糊、吵吵闹闹"，就把两种完全不同的磁场混为一谈。

## 1 字幕还原的论证链（逐帧抓出的关键句）

作者开场先认领观众身份："我将用最直白最不绕弯子的话，对被爱人创死过的观众讲。"然后：

1. **先批李麦是什么结构**：
   - "他俩呢有**习惯惰性和顺服**"；
   - "（一方）去摆脱这个 NPD 的伴侣，**他最后还是被吸回到这个磁铁上**"——即一个人被牢牢吸住、想逃逃不掉。
2. **再讲纯稚是什么结构**：
   - "但我们的纯稚啊——是**两块同性相斥的磁铁**"；
   - 哪怕有"**管理层的离间**"、有"三观对比赛的"拉扯，他们"**所有的力量还都去做朋友**"。
3. **结论**："所以谁再把纯稚和李麦相提并论"就是没看懂这两种磁场的区别。

## 2 两种磁场对照（整理者据字幕提炼）

| | 李麦（再见爱人） | 纯稚 |
|---|---|---|
| 磁学比喻 | **一块磁铁吸一块铁** | **两块同性相斥的磁铁** |
| 受力方向 | 单向：铁被磁铁牢牢吸住 | 双向：既互相顶开、又同处一个磁场 |
| 想逃会怎样 | 挣扎后还是被吸回去（消耗、顺服） | 顶牛、冷战、避开，但斥力=还在相互作用 |
| 关系性质 | 一个拖着另一个，习惯惰性 + 顺服 | 两个独立磁极，所有力量仍指向"做朋友" |

**关键差别**：李麦那种"分不开"是被吸住、跑不掉；纯稚这种"分不开"是**两个独立个体明明在相斥，却谁也没真正离开磁场**——斥力不是羁绊的反面，恰恰是羁绊还活着的证据。

## 4 理论骨架（整理者提炼）

1. **这是全集里唯一一篇"切割向"理论**——它不正面讲纯稚好在哪，而是急着和另一对著名的 toxic 同性 CP（李麦）划清界限。
2. **物理比喻的妙处在于"斥力也是力"。** 作者借磁铁说：纯稚的冷战、顶牛、互不搭理，**不是关系的反面，而是两块同极磁铁之间真实存在的相互作用**——真没关系的两个人，连斥力都没有。
3. **它和 #27 共价键、#30 爱恨共生是一组。** #27 说两人像共价键共享电子对；#30 说爱与恨是同一矛盾的两面；本篇补了个更民间的说法——**相斥也是相吸的一种，是他俩还在一个磁场里的证明**。
4. **"管理层离间"被作者点名为外力。** 和 #22 乡土中国（高层拆 CP）、#28 囚徒困境（外部挤压）一致：都把两人分开归因于外部结构，而非两人自身想分。
5. **本帖是"反李麦"的一方，要和 #6《麦壳说》对读。** #6 是把纯稚整套平移成麦琳×李行亮的相处剧本（情绪方=麦琳位、人机方=李行亮位）；本帖作者恰恰是被这种"幻视"激怒、才搬磁铁做切割——"一块磁铁吸住铁（李麦式消耗）"vs"两块同性相斥的磁铁（纯稚式还在相互作用）"。两篇立场相反但说的是同一件事：纯稚那种"分不开"到底像不像李麦。
6. **高赞评论和作者是同一战线。** 点赞最高的 catslovejazz 不是在反驳视频，而是和作者一起骂"把纯稚往李麦那套里套"的做法——作者自己一开始都会错了意。两人共同的靶子是"外人别拿别的关系框纯稚、更别插进他们两人之间"。
