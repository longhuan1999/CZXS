## 0 一句话概括

火树一针见血：纯稚矛盾的**组织根源**是——有天赋又努力的白小纯，被俱乐部从"核心位"调到了"牺牲位 / 看仓库位"（等于被冷藏、被边缘化）；他本想在当兄弟的青稚那里讨一句"你受委屈了"，结果青稚**既没看见他的痛苦、还继续拿标准 push 他、甚至站在管理层那边**。矛盾的本质不是"谁打得好不好"，而是"**我在职场被牺牲了，而我最好的朋友没有站我这边**"。

---

## 1 什么叫"看仓库"（电竞黑话）

评论区用一句话把这个比喻钉死了（不吃薯片小转，1432 赞）：

> **白小纯："我明明有实力做核心成员，现在却让我成为牺牲位去看仓库，凭什么我被牺牲？"**
> **青稚："（对一个被迫看仓库的成员说）你怎么不努力？"**

- "看仓库"是电竞梗，指选手被按在板凳、调到非核心的牺牲/功能位，**像被塞进仓库里落灰**——有实力、有天赋，却不被放在主位上。
- 火树的关键判断（作者置顶补充）：就算和平精英是 TPS、换位置没 MOBA 那么伤，**只要被换的人有天赋又努力，哪怕一丁点位置变动都足够让他不痛快**——"拿降薪打比方：不涨反降，哪怕只降一两千也很难受。"

## 3 理论骨架（整理者提炼）

1. **这是全集里唯一"从组织行为学/职场逻辑"开刀的一篇。** 前面 #9 四人假说讲的是两人之间怎么错位，本篇往前追一步：**错位的导火索是一次组织上的不公（核心位→仓库位）**。
2. **伤害 = 职场牺牲 × 朋友缺席，两者缺一不可。** 单是被调位，他能忍；单是朋友普通，他也不抱期待。偏偏是"我把你当兄弟，你却没站我这边"——**背叛感来自"朋友位置被当成同事位置用了"**（评论金句："不能占着朋友的位置只做同事的事"）。
3. **火树的"20 年追竞"身份是论据。** 他不是观众，他知道"换位=降薪"对一个有天赋的选手意味着什么，所以他一上来就说"先从电竞角度盘源头"，而不是直接谈感情。
4. **它给 #9 四人假说补上了"现实地基"。** #9 说两人对着幻影相处；本篇解释了白小纯那个"你不站我"的幻影是怎么来的——它不是凭空的，是被一次真实的岗位牺牲和朋友失约喂养出来的。
5. **立场撕裂是这篇的副产品。** 评论自然分成"成绩派（站青稚）"和"情绪派（站白小纯）"——这正是后来全网吵架的缩影：**用竞技理性看，青稚没错；用亲密关系看，白小纯没说错。**

## 4 术语对照

| 词 | 含义 |
|---|---|
| 看仓库 / 仓库位 | 电竞梗：被从核心位调到牺牲/板凳位，像被塞进仓库落灰 |
| 牺牲位 | 为团队战术牺牲个人数据/出场的功能位 |
| MOBA vs TPS | 换位在 MOBA 里伤筋动骨，在 TPS（和平精英）里相对常见，但情绪伤害同样成立 |
| 换位=降薪 | 火树式比喻：有天赋的人被微调位置都难受，像不涨反降哪怕一两千 |
| 被看见 | 评论区共识：白小纯要的不是赢官司，是朋友看见他的委屈 |
| 成绩派 vs 情绪派 | 评论里自然分裂的两种观众立场 |
