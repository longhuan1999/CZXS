## 0 一句话概括

纯稚之间的羁绊像**共价键（covalent bond）**：不是谁单方面贴着谁，而是两个原子**共享一对电子、双向拉扯、互相磨合**的结构性连接；外部（俱乐部/管理层 glc、中间人）像"电子对互斥"从外面挤压，他们就得在排斥里重新找角度、找平衡——**只有双向调整才能形成能量最低的稳定构型，单方向硬扭只会直接断键**。

## 2 Caption：共价键模型逐句

1. **共价键 = 内核相连的结构性连接。** 它是一种"分子内作用力"，两个人共享电子对，**双向拉扯、互相磨合，不是谁单方面贴着谁**。
2. **外部因素 = 电子对互斥。** glc（俱乐部/管理层）、中间人等外部因素就像电子对互斥，从外面挤压原本结构，体系就不稳定了。这时他们必须**调整自己的构型，在排斥里重新找角度、找平衡**，找到一个更稳定、更合适的位置。
3. **这个过程漫长又煎熬。** 因为要改变结构去适配对方。而且共价键是**双向共享**的——**如果只有一方强行扭曲结构，这个体系会直接断裂，根本形成不了最后稳定的构型**。
4. **一旦找到最稳定状态，就很难拆开。** 整个体系非常稳，不容易解离断裂，因为它已经是一个**能量最低、结构最优的整体**。
5. **现在的争吵 = 在找最适配构型。** 感觉他们现在就是在寻找那个最稳定的状态；而找到它肯定需要争吵——不然无法了解对方和自己真正在意的地方，就找不到最适配的状态。

> 作者金句：**"我们不是没有排斥，我们是在排斥里重新找到了彼此最合适的角度。"**

## 4 理论骨架（整理者提炼）

1. **关键词是"双向"。** 共价键区别于"一方依附另一方"的模型：电子对是共享的，拉扯是相互的。作者特意强调"不是谁单方面贴着谁"——这直接回应了评论里那种"谁在倒贴"的读法。
2. **外部压力不是拆散他们的理由，而是逼他们重构构型的外力。** glc、中间人这些"电子对互斥"把他们从舒服的旧构型里挤出来，痛苦但必要。
3. **单相思式硬扭必断。** 共价键是双向共享的——只有一个人改，键直接断。这解释了为什么"单方面付出"在这段关系里不成立，也呼应 #21 印刻效应里"互相"的前提。
4. **现在的吵，是找最低能量构型的必经之路。** 作者不把争吵看成关系破裂，而看成分子在排斥里试探键角——吵完才能知道彼此真正在意什么。
5. **与全集互文**：和 #22《乡土中国》"差序最内圈不可替换"、#23《黄铜胆瓶》"迟到救援"、#28《囚徒困境》"互相背叛"并置看，本篇提供的是**最乐观的一个模型**——它相信这段关系最后会抵达一个"拆不开"的稳态。
