---

## 0 一句话概括

白小纯和青稚不是"不会说话"，而是**共用一本私人词典**：同一个词，大众一个意思、他俩一个意思。于是全网分析文满天飞，他俩却觉得"你们根本听不懂我们在说什么"——这是一场只有两个人参与的"加密通话"。

---

## 1 作者列的三个"词的私人用法"（原话转写）

**① "包庇"被当成褒义的"包容"用。**
- 白小纯公开说过"我们剩下三个都是很**包庇**他的"；可在悬崖对谈里他又正经用过"包容"。
- 大众眼里"包庇"是贬义词；但在他俩词库里，"包庇"可能 = **无条件保护对方、永远站他这边、给他兜底**。而他正经说"包容"的时候，反而带着委屈——"以前一直都是我们在包容"。**贬词褒用、褒词带委屈，混着来。**

**② "腼腆"是他俩的高频暗号。**
- 白小纯第一天后采说"（跟他睡）有点**腼腆**"；青稚在给哥哥的信里也用了"**腼腆**"。
- 作者推测：在他俩的词典里，"腼腆"不是害羞，而是**收敛、有所保留、没把话全说开**。白小纯说"不想跟他睡我很奇怪"，其实是在众目睽睽下给青稚留面子、没直说"我不想和你一屋"——但这句"绕着说"对青稚的杀伤力是加倍的。

**③ "家"= 和哥哥同住的那个空间；"不想和他睡"= 不想回家。**
- 青稚在道歉时说"他晚上**回家**在床上打游戏""我俩在**家里**商量的时候"——他把宿舍叫"家"。
- 结合"不想和他睡"读：白小纯第一天说"不想跟他睡"，私人词典里可能是"**不想回家睡**"；所谓"和好"= **回到同一个家的关系**。
- 延伸：弟弟从单手（马叔）那里给哥哥争取到另一个房间，哥哥"住外面没回家"，弟弟却心甘情愿睡家里沙发好几晚——"因为这是我和哥哥的家"；哥哥说"还不想和好"= **还不想回家**；最新一期"土皇帝抱着被子离家出走"= 又一次"不回家"。

**还没完**：作者说"装"也未必是大众理解的装——白小纯说"他来帮我搬行李我会觉得很装"，这个"装"在他俩语系统里可能另有所指（样本不足，存疑）。

## 2 理论骨架（整理者提炼）

1. **成因：封闭环境 + 中二 + 一起打游戏。** 两个文化程度不高的人，在常年封闭的战队宿舍里朝夕相处，自然会长出**私人语料库**——这在亲密关系里很常见（情侣暗号），只是他俩恰好是两个男的电竞选手。
2. **它把"沟通不畅"重新定性。** 以前大家说他俩"词不达意、丈育"；本篇说：**不是说不好，是外人拿错了字典**。你按公制读，当然读成"吵架"，他俩按私制读，是另一套意思。
3. **"加密通话"是嗑点也是壁垒。** "除了他俩以外都是外人""全网分析文他们根本不看，因为听不懂我们在说什么"——**私人语言本身成了亲密的证明**：我有一套只有你能解码的密码。
4. **和 #17 竞男语言正好一对。** #17 说"竞男对外人说话直、是职业语域"；本篇说"纯稚两个人之间另有一套更私人的字典"——一个是对外的通用语，一个是对内的密码。
5. **作者自己保持谦逊**：开头就讲"样本还少、就当个脑洞"。这是全集中少有的**自我设限**的理论，整理者原样保留这个边界。

## 3 术语对照

| 词 | 大众意思 | 纯稚私人词典里可能是 |
|---|---|---|
| 包庇 | 贬：袒护错误 | 无条件兜底、永远站你这边 |
| 包容 | 褒：大度 | 带委屈的"一直是我让着你" |
| 腼腆 | 害羞 | 收敛、有所保留、没把话说开 |
| 不想和他睡 | 字面排斥 | 不想"回家"（回到和哥哥同住的家） |
| 家 | 住宅 | 和哥哥同住的那个宿舍空间 |
| 和好 | 重归于好 | 回到"同一个家"的关系 |
| 装 | 作假 | 待考，私人义未完全破解 |
| 加密通话 | 比喻 | 只有俩人能解码的私人语系统 |
