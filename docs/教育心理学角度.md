## 0 一句话概括

一个 27 考研的同学，复习[《教育心理学》](./教育心理学角度.md)时顺手把纯稚当成了例题：青稚对应"**高趋低避、自我效能感高**"的那类学生，白小纯对应"**高趋高避、缺失需要没被满足、有点习得性无助**"的那类学生——本质是拿一套课堂上的动机/归因/需要层次理论，给两个人"对号入座"。

---

## 1 作者给两人列的"教心体检表"

### 青稚（qz）

1. **自我效能感高**：班杜拉的概念，指"个体对自己能否做成某事的主观判断"。青稚靠**替代强化**（看别人努力然后进步）＋**直接强化**（自己努力然后成功），把这个判断养得很高。
2. **交往动机**：因为想和白小纯修复友情，所以能听得进别人的意见——这属于"出于人际关系而去学习/改变"的动机。
3. **高趋低避者**（自我价值感理论）：通过不断努力来发展自我，趋成功、避失败的压力较小。

### 白小纯（bxc）

1. **成败归因理论 / 习得性无助**：努力之后没成功，又被**错误地归因于"努力"**，于是慢慢形成习得性无助。
2. **动机从内部滑向外部**：最初是内部动机——想夺冠、想在电竞领域有所建树；夺冠后发现这很挣钱，叠加了外部动机，现在是"内部＋外部"双动机。
3. **马斯洛需要层次**：转会压力使他的"缺失需要"一连串没被满足——生存需要、安全需要、**归属与爱的需要、尊重/理解的需要**都悬空。

作者收尾很学生气：「我不晓得啊啊啊，今晚整理例子时突然觉得他俩很典型？」标签直接挂 #27考研 #身边的心理学。

## 3 理论骨架（整理者提炼）

> 本说的价值不在结论多深，而在它提供了一张**把综艺人物翻译成教材术语的对照表**。

1. **两人是同一量表上的两个极端。** 用"自我价值感取向"量：青稚是**高趋低避**（敢努力、不怕试错），白小纯被评论区修正为**高趋高避**（想赢却怕输、偷偷努力却不敢立目标）。
2. **白小纯的问题被归到"需要没被满足"。** 马斯洛框架下，他不是不想赢，而是**底层的尊重需要、归属与爱的需要一直悬空**，上面的成就动机自然立不住。
3. **"习得性无助"被同学当场纠错。** 评论区指出：真要套这个概念，得是把失败归因为"我能力不行"（稳定不可控）才成立；作者原写的"归因于努力"其实套错了——这恰好是这条帖子最"考研现场"的地方。
4. **外部动机是把双刃剑（德西效应）。** 夺冠+挣钱之后，外部动机上涨，反而可能侵蚀掉最初"想夺冠"的那点内部热爱——这被用来解释他现在的拧巴。
5. **它开的药方也是教心式的。** 不是"你俩好好沟通"，而是"**把归因重新引导到'努力'这个可控因素上**""**用 ABC 理论修正不合理信念**"——把这段关系当成一个需要做认知辅导的学生个案。

## 4 术语对照（教材版）

| 术语 | 在本说里指谁/什么 |
|---|---|
| 自我效能感（班杜拉） | 青稚"我努力就能成"的高判断 |
| 替代强化 / 直接强化 | 看别人进步 / 自己成功，两种养自信的途径 |
| 交往动机 | 青稚为修复友情而听得进劝 |
| 高趋低避 / 高趋高避 | 青稚敢拼不怕错；白小纯想赢又怕输、偷偷努力 |
| 成败归因 / 习得性无助 | 白小纯努力没成后的无力感（评论区：要归到"能力"才成立） |
| 内部动机 / 外部动机 / 德西效应 | 为爱夺冠 → 发现挣钱 → 外部动机反噬内部动机 |
| 马斯洛缺失需要 | 白小悬空的"尊重、归属与爱" |
| 埃里克森阶段 | 勤奋vs自卑、亲密vs孤独 |
| ABC 合理情绪疗法 | 评论区开的"给 bxc 做认知辅导"药方 |
