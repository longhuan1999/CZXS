### 课件来源清单共创说明

请参考格式`[@用户名](用户主页分享链接).[[课件媒体类型图标]课件名称](课件分享链接).[课件来源类型]`，如： `[@1An1](https://xhslink.cn/o/61YIpKZeqgZ).[📄纯稚学的课件大全又名《纯稚怎么翻译？》1.0](https://xhslink.cn/o/7nimkkErq84).[小红书图文]`

课件媒体类型图标：

 - 📄：图文
 - 📺：视频
 - 🖼：图片、截图
 - 🌐：网站
 - 其他自定义

课件来源类型，如：
 - 小红书图文
 - 小红书视频
 - 抖音视频
 - 抖音图文
 - 豆瓣图文
 - 微博图文
 - 其他自定义

**用户主页分享链接** 和 **课件分享链接** 建议使用网站或App生成的分享链接，而不是直链。因为大多数情况下，直链不适合手机端跳转到App内浏览。**小红书** 特别需要注意，分享链接最好在小红书App内生成，直链和PC网页端生成的分享链接，容易遭遇手机端自动跳转App但不自动打开对应笔记，以及PC网页端风控提示笔记暂时无法访问的情况。
